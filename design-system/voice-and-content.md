# Voice, Tone & Content Standards — TI Design System v2.1 (§10)

Use this file as the standing instruction set for any AI-generated copy: marketing, course descriptions, email, UI labels, webinar scripts, and document edits. It also doubles as evaluation criteria — an AI can grade its own output against it before handing it back.

## The Institutes voice

Authoritative but not cold. We write for serious professionals the way a respected colleague would — not a textbook, not a bureaucracy.

- **Clear** — No unnecessary jargon. Technical insurance/risk terms are fine; complexity for its own sake is not.
- **Confident** — We know the material. We do not hedge unnecessarily.
- **Encouraging** — Our learners work hard. We write like we are on their side.
- **Precise** — In credentialing, precision is part of the product. Vague claims undermine trust.

This ladders up to the three brand attributes (§3): **Authority, Accessibility, Forward-looking.**

## Tone by context

| Context | Tone |
|---------|------|
| Homepage / Marketing | Aspirational; action-oriented; short sentences; clear value proposition |
| Designation pages | Authoritative; benefit-structured; peer-level respect for the reader |
| Course content | Instructional; structured; learner-centered |
| Error messages | Calm, direct, helpful — **never blame the user** |
| Confirmation messages | Warm, brief, affirming |
| CEU / Compliance | Precise; regulatory accuracy is non-negotiable |
| Email (marketing) | Direct, value-first, single clear CTA |

## Content standards (hard rules)

1. **UI labels are sentence case.** Exceptions: designation names, proper nouns, and H5/uppercase labels.
2. **Designation names use approved trademark format:** CPCU®, ARM™, AIAI™. Never abbreviate or modify without approval.
3. **Reading level:** Grade 10–12 for marketing; Grade 12–14 for course content.
4. **Links are descriptive — never "click here."** Link text tells the user exactly where they are going.
5. **Numbers:** spell out under 10 in body text; numerals for 10+, for measurements, and in all UI and pricing contexts.

## Button & CTA copy

- Action-verb-first; four words or fewer (except established uppercase patterns like `ADD TO CART`).
- One primary CTA per view/email.

## AI-specific review notes (§2)

- AI tools occasionally hedge unnecessarily or reach for jargon — review for confidence and clarity.
- AI-origin content is held to the same review standard as human-authored content. Origin does not change the bar.
- "Rewrite this section **in The Institutes voice**" with this file in context beats a bare "rewrite this section."
